Auto Content Ratings

Looks up the official content rating (U, PG, 12A, 15, 18...) for movies and series and writes it to each item's Parental Rating.

Data source

You can use a different source for each, e.g. TMDB for movies and TVDB for TV. Enter an API key for each source you use.
A v3 API key or v4 read access token from themoviedb.org/settings/api.
A v4 project API key from thetvdb.com.
Only needed for user-supported API keys.
Only works if you have entered an API key for both sources.

Rating country

Picks which country's rating board to use, e.g. United Kingdom gives BBFC ratings (U, PG, 12A, 15, 18).
Uses the table below, e.g. TV-MA becomes 18. These are equivalents, not official ratings. A rating from your chosen country always takes priority.
The defaults are for UK (BBFC) ratings and lean cautious where there is no exact match. US ratings not listed are not converted.

Libraries

Only movies and series in the ticked libraries are updated.

Schedule

Picks up ratings that have changed upstream. Both schedules also appear under Dashboard > Scheduled Tasks.

Options

When off, only items with no rating are filled in.
Same as editing a series' rating in Jellyfin's metadata editor. Recommended if you use parental controls.
Matches Jellyfin's built-in TMDB provider. Useful if your libraries mix ratings from several countries.
For items where the Parental Rating field is locked. Items locked as a whole ("Lock this item to prevent future changes") are always left alone. Use "Check whole library now" to apply this to existing items.
Stops a later metadata refresh from changing it back. The plugin will then only update it again if "Ratings you have locked" is set to update them. Takes priority over unlocking.
